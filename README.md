# 10문 10답 AI 인터뷰

AI 인터뷰어가 딱 10개의 질문을 하나씩 던지고, 답변에 따라 다음 질문을 정해 그 사람의 핵심을 짧은 보고서로 정리해 주는 모바일 웹앱(PWA)입니다. 서버 없이 정적 파일만으로 동작합니다.

## 실행

```bash
cd interview
python3 -m http.server 8000   # 아무 정적 서버나 가능
```
휴대폰에서 열고 설정에서 API 키(Anthropic 또는 OpenAI)를 입력하면 시작할 수 있습니다.
GitHub Pages·Netlify 등에 `interview/` 폴더를 그대로 올려도 됩니다. (Service Worker와 공유 시트는 HTTPS에서 동작)

## 구조

| 파일 | 역할 |
|---|---|
| `js/prompts.js` | **모든 프롬프트** (인터뷰어 페르소나, 질문 원칙, 보고서 지시, JSON 스키마) |
| `js/interview.js` | 10문항 흐름: 질문 수 계산, 다룬 영역 추적, 후속질문 규칙, 보고서 검증 |
| `js/llm.js` | Anthropic / OpenAI 직접 호출, JSON 파싱, 오류 처리 |
| `js/storage.js` | localStorage (인터뷰, 보고서, 설정) |
| `js/share.js` | 이미지 저장(html2canvas), 공유 시트, 텍스트 복사 |
| `js/app.js` | 해시 라우팅과 6개 화면 |
| `vendor/html2canvas.min.js` | html2canvas 1.4.1 (MIT) |

## 질문 품질을 위한 장치

- 매 질문 요청에 **지금 몇 번째인지, 이 질문을 포함해 몇 개 남았는지**, 다룬 영역과 아직 안 다룬 영역을 함께 보냅니다. AI는 `remainingPlan`(남은 질문으로 무엇을 다룰지)을 매번 스스로 세운 뒤 질문을 고릅니다. (사용자에게는 질문만 보입니다)
- 코드가 상황에 맞춰 규칙을 덧붙입니다: 연속 후속질문 2번 뒤에는 새 영역으로 넘어가기, 7번째까지 후속질문이 없으면 반드시 후속질문, 남은 질문 수가 안 다룬 영역 수 이하이면 새 영역 우선, 마지막 질문은 마무리용.
- 질문 개수는 AI가 아니라 코드가 세므로 정확히 10번째 답변 뒤에 분석으로 넘어갑니다.
- 보고서의 인용은 실제 답변 원문과 대조하고, 맞지 않으면 한 번 다시 요청합니다.

## 결과물: 공유용 시 + 나만 보는 편지·분석

- **공유용 카드**: 상징 이미지, 시 한 편, 키워드 3개. 사적인 내용(이름, 장소, 사건, 답변 원문)은 은유로만 바꿔 쓰도록 지시하고, 코드가 시에 답변 원문이 9글자 이상 그대로 들어갔는지 검사해 다시 요청하거나 그 행을 뺍니다. 이미지 저장과 공유 시트에는 이 카드만 담깁니다.
- **나만 보기**: 인터뷰어가 보내는 편지, 그리고 근거 인용이 붙은 분석(접혀 있음). 공유되지 않습니다.

## 다른 인터뷰 모드 추가 (예: 부모님 인터뷰)

`prompts.js`의 `PERSONAS`에 항목을 하나 추가하고, `createInterview(name, '<persona id>')`로 시작하면 됩니다.

## 개인정보

API 키와 모든 기록은 이 기기의 브라우저(localStorage)에만 저장되며, 선택한 AI 회사의 API 외에는 어디로도 전송되지 않습니다.
