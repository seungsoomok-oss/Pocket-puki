# Ideas — 아이디어 뉴럴 맵 (PWA)

떠오른 서비스·상품 아이디어를 말이나 글로 바로 기록하면, Claude가 키워드·요약을 만들고 연관된 아이디어끼리 이어 묶음으로 정리해 뉴럴 맵으로 보여주는 개인용 모바일 웹앱.

- 빌드 없음. 정적 파일만 올리면 동작 (HTTPS 필요)
- 데이터: 기기 안 IndexedDB. 백업은 설정 → 내보내기/불러오기(JSON)
- 오프라인: 기록은 바로 저장되고, 연결되면 대기열을 처리

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `app.js` | 기록(음성/글), 상세 시트, 설정 |
| `map.js` | d3-force 뉴럴 맵, 확대·이동 |
| `ai.js` | Claude API 프롬프트(JSON 스키마 출력), 처리 대기열, 물방울 그룹, 영감 제안 |
| `db.js` | IndexedDB, 내보내기/불러오기 |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA |
| `vendor/d3.min.js` | d3 v7.9.0 |

## Claude 처리 흐름
1. 저장 → `pending` 상태로 기록
2. 온라인이면 아이디어마다 1회 호출: 키워드, 한 줄 요약, 연관 아이디어 id, 묶음(기존 or 새 이름)
3. 새 아이디어 5개마다(또는 설정의 "다시 묶기") 전체 재정리: 묶음과 이름, 연결, 물방울(같은/상위 아이디어)을 다시 계산

## 화면에서 하는 일 세 가지
- **기록:** 마이크(한국어 음성) 또는 입력창. `?`로 시작하면 질문(처음 3번만 안내 표시)
- **보기:** 뉴럴 맵. 사실상 같은 아이디어나 상위·하위 관계인 아이디어는 물방울 하나로 합쳐짐(숫자 = 개수). 탭하면 갈라져 각각 보이고, 바깥을 탭하면 다시 뭉침
- **영감(+):** 화면 가운데 조준점. 맵을 끌어 원하는 아이디어에 맞추면 +가 밝아지고, 누르면 그곳을 씨앗으로 노트 전체 + 바깥 요소(시장·기술·사례)를 엮은 새 아이디어 제안 → 보관/폐기

## 그 밖의 기능
- **질문 결과:** 분석 의견 + 고른 아이디어 목록, 맵에서 하이라이트. 결과는 설정 → 질문 내역에 저장(다시 열어도 비용 없음)
- **개발 프롬프트:** 상세 화면 `프롬프트` 버튼. AI 코딩 도구에 붙여넣을 MVP 지시문 (항상 고급 모델)
- **모델:** 기본 Haiku / 중급 Sonnet / 고급 Opus. 설정 → 사용량에서 토큰과 대략 비용 확인

## 로컬 실행
```
python3 -m http.server 8000
```
