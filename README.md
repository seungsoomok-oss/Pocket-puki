# Ideas — 아이디어 뉴럴 맵 (PWA)

떠오른 서비스·상품 아이디어를 말이나 글로 바로 기록하면, Claude가 키워드·요약을 만들고 연관된 아이디어끼리 이어 묶음으로 정리해 뉴럴 맵으로 보여주는 개인용 모바일 웹앱.

- 빌드 없음. 정적 파일만 올리면 동작 (HTTPS 필요)
- 데이터: 기기 안 IndexedDB. 백업은 설정 → 내보내기/불러오기(JSON)
- 오프라인: 기록은 바로 저장되고, 연결되면 대기열을 처리

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `app.js` | 기록(음성/글), 상세 시트, 설정 |
| `map.js` | d3-force 뉴럴 맵, 확대·이동 |
| `ai.js` | Claude API 프롬프트(JSON 스키마 출력)와 처리 대기열 |
| `db.js` | IndexedDB, 내보내기/불러오기 |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA |
| `vendor/d3.min.js` | d3 v7.9.0 |

## Claude 처리 흐름
1. 저장 → `pending` 상태로 기록
2. 온라인이면 아이디어마다 1회 호출: 키워드, 한 줄 요약, 연관 아이디어 id, 묶음(기존 or 새 이름)
3. 새 아이디어 5개마다(또는 설정의 "다시 묶기") 전체 재정리: 묶음과 이름, 연결을 다시 계산

## 로컬 실행
```
python3 -m http.server 8000
```
